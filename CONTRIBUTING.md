# Contributing / Участие в разработке

This is an early community preview. Bug reports, docs fixes and tests are welcome.

1. Open an issue describing the problem or improvement. Do not include tokens, client data, webhook bodies or private message screenshots.
2. Fork the repository and create a focused branch.
3. Add tests for behavioral changes, then run `python -m pytest -q`.
4. Open a pull request with a concise summary, compatibility notes and security impact.

## Обсуждение изменений

Приветствуются улучшения документации, тестов и совместимости с MAX API. В PR описывайте изменение и способ проверки. Сообщения коммитов можно писать по-русски.

**Do not post live API credentials or production conversation data.**
