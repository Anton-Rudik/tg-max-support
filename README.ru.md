# TG + MAX Support Desk

**Универсальный открытый проект для поддержки клиентов в Telegram и MAX через одну Telegram-супергруппу.**

[English README](README.md) · [Подробная установка на PM2](docs/DEPLOY_RU.md) · [Безопасность](SECURITY.md) · [Как участвовать](CONTRIBUTING.md)

> **Статус: ранний прототип.** Автоматизированные тесты прошли, но работа с реальными Telegram/MAX ботами ещё не проверена. Перед использованием в рабочем окружении необходимы интеграционные испытания, резервные копии и политика обработки персональных данных.

## Принцип работы

Клиент запускает Telegram-бота или MAX-бота, получает приветствие и комплект материалов. Для каждого клиентского аккаунта при первом обращении создаётся **своя постоянная тема** в закрытой Telegram-супергруппе. Ответы всех авторизованных менеджеров из темы пересылаются клиенту от имени бота, без упоминания имён сотрудников.

### Возможности

- Приветственное сообщение и автоматическая выдача материалов разных форматов.
- Управление материалами через `/admin`: загрузка, удаление, сортировка, предпросмотр, публикация, версии.
- Несколько менеджеров могут одновременно общаться с одним клиентом, независимо от того, кто взял заявку.
- Повторные обращения идут в ту же тему.
- Поиск клиентов, статусы обращений, уведомления об отсутствии ответа.
- Общая SQL-база, очередь сообщений и повторы при временных ошибках.
- Настраиваемое имя проекта, приветствие и язык клиентского меню (`ru` / `en`). Управление менеджерами пока на русском.
- Запуск Python через PM2, без Docker.

## Быстрый запуск

Нужны: Python 3.11+, PostgreSQL, PM2, HTTPS-домен, Telegram-бот и закрытая супергруппа с темами. MAX подключается дополнительно после получения токена.

```bash
git clone https://github.com/Anton-Rudik/tg-max-support.git
cd tg-max-support
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# Заполнить .env; создать базу PostgreSQL и настроить HTTPS
.venv/bin/python -m pytest -q
pm2 start ecosystem.config.cjs
pm2 save
```

После запуска HTTPS:

```bash
.venv/bin/python -m scripts.register_webhooks --platform tg
# Когда MAX готов:
.venv/bin/python -m scripts.register_webhooks --platform max
```

Подробные шаги для VPS и Nginx: **[docs/DEPLOY_RU.md](docs/DEPLOY_RU.md)**.

## Основные параметры `.env`

- `TG_BOT_TOKEN`, `TG_GROUP_ID`, `TG_WEBHOOK_SECRET`, `ADMIN_IDS` — Telegram и менеджеры.
- `MAX_BOT_TOKEN`, `MAX_WEBHOOK_SECRET` — необязательно до подключения MAX.
- `PUBLIC_BASE_URL` — публичный HTTPS-домен.
- `DATABASE_URL` — подключение к PostgreSQL.
- `PROJECT_NAME`, `UI_LANGUAGE`, `WELCOME_TEXT` — название, язык и приветствие.
- `STORAGE_DIR` — локальное файловое хранилище материалов.

Изменения `WELCOME_TEXT` после первого запуска не переписывают приветствие в базе — используйте `/admin`.

**Не публикуйте `.env`, токены, дампы базы и реальные сообщения клиентов.** Все участники рабочей Telegram-супергруппы могут видеть её доступные темы, поэтому добавляйте только доверенных сотрудников.
