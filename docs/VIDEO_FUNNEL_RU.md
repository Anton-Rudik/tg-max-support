# Сценарий из 5 видео: 4 автоматически + 1 по кнопке

Пример универсальной воронки. Слова в подписях можно менять через `/admin`; ролики **не включены** в репозиторий. Сценарий применяется только после того, как администратор добавил материалы и опубликовал версию.

## Последовательность

1. Короткое приветствие (из `/admin` → «Приветствие»).
2. Видеоматериал «50,1% — авторская стратегия» с подписью.
3. Видео №1 — «4 способа создать второй источник дохода до 300 000 ₽/мес в 2026 году» (это название ролика, а не обещание результата).
4. Видео №2 — «Два способа начать зарабатывать на инвестициях в спорт».
5. Видео №3 — «Третье АРХИВАЖНОЕ видео из серии “Как зарабатывать на спорте вторую зарплату?”».
6. Сообщение с приглашением и кнопкой «Посмотреть».
7. После нажатия: видео №4 — обзор клуба с отдельной подписью.

### Текст приглашения

> Если не хочется самостоятельно во всём разбираться и тратить время на поиск решений, я подготовил ещё одно видео. В нём расскажу, как устроен наш клуб, что получает участник и какие форматы участия доступны. Нажми «Посмотреть», чтобы познакомиться поближе 👇

## Настройка через админ-бота

1. Откройте `/admin`, установите короткое приветствие.
2. Нажмите «📎 Файл/фото/видео» и по очереди пришлите **четыре** видео (стратегия 50,1%, затем №1, №2 и №3). Для каждого укажите подпись к сообщению. Порядок можно менять стрелками «↑» и «↓» в «Черновике».
3. Нажмите «🎬 Видео после кнопки» и отправьте видео №4 с подписью.
4. Нажмите «🗣 Текст приглашения» и отправьте текст выше (или свой).
5. Нажмите «🔘 Текст кнопки» и укажите «Посмотреть».
6. Проверьте «Предпросмотр» и нажмите «🚀 Опубликовать».
7. Протестируйте новым клиентским аккаунтом: первое приветствие → 4 видео → CTA; видео №4 должно прийти только после нажатия.

## Видео до 300 МБ

**Telegram.** Отправляйте исходное видео в личный чат **того же бота** как видео (а не пересылаемое сообщение клиенту). Система сохраняет `file_id`, а затем использует `sendVideo` с `file_id`. Это **новое сообщение от бота**, не forward и без надписи об источнике. Telegram не требует повторной загрузки файла на сервер; идентификатор относится только к данному боту. Не меняйте токен на токен другого бота, если хотите использовать старые `file_id`.

**MAX.** Для типа `video` разрешены файлы до **250 МБ**. Для каждого ролика больше 20 МБ подготовьте отдельный, оптимизированный MP4 до 250 МБ. Положите его на сервер в `STORAGE_DIR/max/` (по умолчанию `data/materials/max/`), затем в личном чате админа введите:

```
/max_file 123 имя_файла.mp4
```

Здесь `123` — ID видеоматериала из списка «Черновик». Публикуйте черновик только после привязки альтернативных видео для MAX. Видеофайлы **не нужно загружать на GitHub**.

Для файлов до 20 МБ, которые были загружены в админ-бот, система сохраняет локальную копию для MAX. Для больших видео Telegram может использовать только `file_id`; MAX требует отдельный локальный файл или ранее созданный токен. В текущей версии админ-панель не занимается автоматическим сжатием больших видео.

### Важные ограничения

- Повторное нажатие «Посмотреть» повторно отправляет видео №4 — это осознанное поведение, а не отдельная новая заявка.
- Приветствие и комплект выдаются только при первом входе; повторный запрос через «Материалы» отдаёт первые четыре видео и кнопку снова.
- Обновления списка материалов публикуются версиями. Старые задания на отправку используют старые версии до завершения очереди.
- Используйте материалы, на распространение которых у вас есть права; описания о заработке не должны содержать недостоверных гарантий доходности.

Источник ограничений: https://core.telegram.org/bots/api (Sending files, sendVideo), https://dev.max.ru/docs-api/use-cases/sending-messages/media/.
